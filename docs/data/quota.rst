配额申请
=============


流程目标
^^^^^^^^

当默认配额（CPU/存储）不足、或需要申请项目组级别的额外资源时，使用
本流程提交配额申请。管理员审批通过后，配额会自动到账。

进入方式
^^^^^^^^

点击左侧菜单 ``配额申请``，进入配额申请页面。普通用户侧栏默认包含
此菜单。

页面内容
^^^^^^^^

页面顶部是 ``我的申请`` 标签，标签右侧有两个按钮：``刷新`` 和 ``新建
申请``。点击 ``刷新`` 重新载入列表；点击 ``新建申请`` 弹出申请表单。

标签下方是申请列表表格，列包含：``申请编号``、``申请人``、``所属项目``、
``申请金额``、``期望CPU核数``、``期望存储``、``申请理由``、``状态``、
``提交时间``。

   :width: 90%

   配额申请页面，含 ``我的申请`` 标签、``刷新`` 和 ``新建申请`` 按钮、

新建申请流程
^^^^^^^^^^^^

1. 在配额申请页面点击 ``新建申请`` 按钮，弹出 ``新建配额申请`` 表单。
2. 填写表单字段：

   - ``申请金额（元）``：必填，希望申请的资源金额（单位：元）。
   - ``期望 CPU 配额（核数，可选）``：希望获得的 CPU 核数（如不填则
     仅申请金额）。
   - ``期望存储空间（可选）``：希望获得的存储空间，单位 GB（如不填
     则仅申请金额）。
   - ``所属项目组（可选）``：下拉选择项目组；不填则为个人申请。
   - ``申请理由``：必填，简要说明申请原因，例如：因 XX 项目数据量
     大，需要额外存储空间。

3. 确认无误后点击 ``提 交`` 按钮；如放弃可点击 ``取 消``。
4. 看到提交成功提示后，新申请出现在 ``我的申请`` 列表中，状态为
   ``待审批``。

.. figure:: /_static/resource-new.png
   :alt: 新建配额申请表单
   :width: 90%

   新建配额申请表单，含申请金额、CPU 配额、存储空间、所属项目组、
   申请理由字段。

查看申请状态
^^^^^^^^^^^^

申请提交后，状态会自动流转：

- ``待审批``：申请已提交，等待管理员审核。
- ``已通过``：申请通过，相应配额已到账。
- ``已驳回``：申请未通过，可在申请列表查看驳回原因。

注意事项
^^^^^^^^

.. note::

   - 申请提交后不可直接修改，如需调整参数可联系管理员驳回后重新提
     交。
   - ``申请金额`` 和 ``申请理由`` 是必填字段，其他字段选填；不填
     的字段表示不申请该项资源。
   - 资源到账需要时间，请耐心等待管理员审批；如长时间未处理，可提
     交工单询问。

.. warning::

   请如实填写申请金额和理由。频繁申请小额资源可能被管理员驳回。
