认识用户工作台
====================

流程目标
^^^^^^^^

让用户登录后知道从哪里开始，以及如何快速判断平台是否正常。

进入方式
^^^^^^^^

登录成功后自动进入工作台；也可以点击左侧菜单 ``工作台`` 随时回到该页
面。

页面内容
^^^^^^^^

工作台由若干卡片组成，依次为：

- ``快捷操作``：三个常用入口按钮 ``应用管理`` ``通知中心``
  ``帮助文档``。
- ``账户概览``：显示用户名、状态、显示名称、用户余额、项目数量、未读通
  知数。
- ``作业统计``：近 7 天作业数量，含 ``运行中`` ``排队中`` ``24h完成``
  ``24h失败`` 四个计数；下方是 ``最近作业`` 表格。
- ``平台通知``：显示最近若干条通知摘要，每条含标题、类型、发布时间，
  右上角 ``查看全部`` 进入完整通知列表。
- ``平台状态``：显示集群在线状态，``2 / 2`` 表示 2 个可用集群共 2 个，
  ``0`` 异常节点。
- ``我的项目组``：列出所属项目组卡片，含组名、ID、CPU/GPU/内存配额。

正常结果
^^^^^^^^

进入工作台后可以看到自己的账号信息、最近作业和通知，不需要任何额外操
作。

使用建议
^^^^^^^^

- 想启动应用 → 点击 ``快捷操作`` 中的 ``应用管理``，或左侧菜单
  ``应用列表``。
- 想看通知 → 点击 ``快捷操作`` 中的 ``通知中心``。
- 想看项目组 → 滚动到工作台最下方的 ``我的项目组`` 卡片，或点击左
  侧菜单 ``项目组管理``。
