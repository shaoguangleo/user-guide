用户注册
=============

流程目标
^^^^^^^^

为首次使用平台、还没有账号的科研人员说明如何注册。已有账号的用户
请直接阅读下一章。

进入方式
^^^^^^^^

在浏览器中打开平台网址 ``https://kylin.cnsrc.shao.ac.cn/Login/``，
进入登录页面。

在登录页点击 ``注册账号`` 按钮（位于页面底部，``登 录`` 和
``Login with SSO`` 按钮下方）。

.. figure:: /_static/login-page.png
   :alt: 登录页
   :width: 90%

   登录页面。点击 ``注册账号`` 按钮进入注册流程。

页面内容
^^^^^^^^

注册页需要填写以下信息：

- ``登录名``：用于登录的用户名，注册后不可修改。
- ``姓名``：真实姓名。
- ``邮箱``：用于接收平台通知、找回密码等。
- ``类型``：下拉选择 ``学生`` 或 ``职工``。
- ``密码``：至少 8 位，必须同时包含大写字母、小写字母和数字。
- ``再次输入密码``：与上面密码一致。

.. figure:: /_static/register-page.png
   :alt: 注册页面
   :width: 90%

   注册页面，含登录名、姓名、邮箱、类型、密码、确认密码字段。

注册流程
^^^^^^^^

1. 在登录页底部点击 ``注册账号`` 按钮。
2. 在注册页填写 ``登录名``、``姓名``、``邮箱``。
3. 在 ``类型`` 下拉中选择 ``学生`` 或 ``职工``。
4. 在 ``密码`` 框中输入符合要求的密码（≥8 位、含大小写字母和数字）。
5. 在 ``再次输入密码`` 框中再次输入相同密码。
6. 点击 ``注 册`` 按钮提交。
7. 注册成功后，页面提示注册成功；如需立即登录可点击 ``返回登录`` 跳
   回登录页，使用新账号登录。

注意事项
^^^^^^^^

.. note::

   - 登录名是您后续登录和被其他用户识别的唯一标识，请谨慎选择。注册
     后登录名通常不可修改。
   - 密码需符合强度要求（至少 8 位、含大小写字母和数字），否则无法
     提交。
   - 注册成功后账号需要管理员审核（``启用``）后才能登录使用。如提
     示 ``账号未启用`` 或 ``账号不存在``，请联系管理员处理。
   - 如忘记密码，可使用登录页的密码重置功能（如果平台开放），或联
     系管理员重置。

.. warning::

   请使用真实邮箱注册，便于接收平台通知和密码找回邮件。
