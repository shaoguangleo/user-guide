退出平台
==============

流程目标
^^^^^^^^

帮助用户安全结束使用。

进入方式
^^^^^^^^

点击页面右上角的 ``用户名`` 头像，弹出下拉菜单。

操作步骤
^^^^^^^^

1. 保存当前应用中的文件。
2. 关闭不再使用的应用（在 ``应用列表`` 页面点击对应卡片上的 ``关 闭``）。
3. 点击右上角头像打开下拉菜单。
4. 在下拉菜单中点击 ``退出登录``。
5. 确认返回到登录页。

.. figure:: /_static/logout-menu.png
   :alt: 退出登录菜单
   :width: 90%

   点击右上角头像后弹出的下拉菜单，包含 ``个人信息`` ``修改密码``
   ``退出登录`` 等。

注意事项
^^^^^^^^

.. warning::

   关闭浏览器窗口不一定等同停止应用或释放作业资源，必须回到
   ``应用列表`` 页面点击 ``关 闭`` 才能真正结束应用并释放资源。

常见问题
^^^^^^^^

- **退出登录后应用是否会自动关闭？**
  不会。必须先在 ``应用列表`` 页面点击 ``关 闭``，然后再退出登录。
