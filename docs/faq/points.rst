申报成果获取积分
======================

流程目标
^^^^^^^^

帮助用户了解积分的来源——积分不是账户余额，而是用户在使用平台过程中取
得的**科研成果**经管理员审批后获得的奖励。本节重点介绍如何申报成果。

进入方式
^^^^^^^^

点击左侧菜单 ``积分管理``，进入积分页面。

积分与余额的区别
^^^^^^^^^^^^^^^^

.. important::

   **积分** 和 **账户余额** 是两个不同概念：

   - 账户余额（工作台 ``账户概览`` 中的 ``用户余额``\ ）：是用户
     充值/扣费的金额，单位是「元」，与计费相关。
   - 积分：是用户申报成果（如论文、专利、报告）并经管理员审批通
     过后获得的奖励，单位是「积分」，可在 ``服务兑换`` 中兑换计算服
     务。

   本节只介绍**积分**及其获取流程。账户余额相关问题请参考计费相关章
   节或联系管理员。

页面内容
^^^^^^^^

积分页面包含四个标签页：

- ``积分概览``：显示 ``可用积分``、``冻结积分``、``累计获得``、
  ``累计消耗`` 四个数值。
- ``积分流水``：积分变动明细。
- ``服务兑换``：用积分兑换计算服务（具体兑换规则由平台管理员发布）。
- ``成果申报``：**最重要的标签**，用户在此提交科研成果。

   :alt: 积分概览
   :width: 90%

   积分概览页面，显示可用积分、冻结积分、累计获得、累计消耗。

成果申报流程
^^^^^^^^^^^^

成果申报是普通用户获得积分的主要途径。流程是：在 ``成果申报`` 标签下
点击 ``新增成果`` → 填写成果信息 → 提交 → 等待管理员审核 → 审核通
过后积分自动到账。

1. 在积分页面顶部点击 ``成果申报`` 标签。
2. 在子标签栏点击 ``新增成果``。
3. 填写 ``成果名称`` （必填，例如：基于 SKA 数据的脉冲星搜寻）。
4. 选择 ``成果类型`` （必填，例如：论文、专利、技术报告等，
   以页面下拉项为准）。
5. 在 ``成果描述`` 中详细描述成果内容（必填），建议包括：

   - 研究背景与目标。
   - 使用了平台的哪些资源（如 CPU 核数、运行时长）。
   - 成果形式（已发表论文、已授权专利、内部报告等）。
   - 关联的项目组或作业 ID（可选）。

6. 如有相关附件（论文 PDF、报告、图表等），点击 ``上传附件`` 选择
   本地文件上传。
7. 填写完成后，点击 ``提交审核`` 按钮提交；如暂时不提交可点击
   ``保存草稿``；如放弃可点击 ``取 消``。
8. 看到成功提示后，切到 ``我的成果`` 标签可查看刚刚提交的成果。

.. figure:: /_static/achievement-new.png
   :alt: 新增成果表单
   :width: 90%

   新增成果表单，填写成果名称、类型、描述并上传附件后提交审核。

查看我的成果与审核状态
^^^^^^^^^^^^^^^^^^^^^^

1. 在 ``成果申报`` 标签下点击 ``我的成果`` 子标签。
2. 列表显示已提交的所有成果，列包含 ``成果名称``、``类型``、
   ``积分``、``状态``、``创建时间``、``附件``、``操作``。
3. 列表上方 ``状态`` 下拉框可按状态筛选。
4. 点击 ``审核状态`` 子标签可看到各状态对应的说明。
5. 列表右上角的 ``新增成果`` 按钮可快速再次提交。

.. figure:: /_static/achievement-list.png
   :alt: 我的成果列表
   :width: 90%

   我的成果列表，列出已提交的所有成果及其审核状态。

审核状态说明
^^^^^^^^^^^^

- ``待审核``：成果已提交，等待管理员审核。
- ``已通过``：成果通过审核，相应积分已到账。
- ``已驳回``：成果未通过审核，可在备注中查看原因后重新提交。
- ``已撤回``：用户主动撤回的成果。

查看积分流水
^^^^^^^^^^^^

1. 在积分页面点击 ``积分流水`` 标签。
2. 页面展示积分变动明细列表。
3. 每条记录包含时间、类型（获得 / 消耗 / 冻结 / 解冻 / 调整）和说明。

.. figure:: /_static/points-flow.png
   :alt: 积分流水
   :width: 90%

   积分流水标签页，展示积分变动记录。

注意事项
^^^^^^^^

.. note::

   - 同一成果请勿重复提交，避免被系统识别为重复并驳回。
   - 管理员审核完成后，积分会直接到账并显示在 ``积分概览`` 的 ``可用
     积分`` 中。审核进度可在 ``我的成果`` 列表中查看。
   - 积分记录或状态异常时，请通过 ``工单管理`` 提交工单联系管理员。
     本手册不介绍管理员审批、调整等操作。

常见问题
^^^^^^^^

- **积分怎么获得？**
  通过 ``积分管理`` → ``成果申报`` → ``新增成果`` 提交科研成果，管
  理员审核通过后积分自动到账。

- **积分可以用来做什么？**
  可在 ``服务兑换`` 标签中兑换平台提供的计算服务（具体兑换规则由管
  理员发布）。

- **已提交的成果可以修改吗？**
  提交后处于 ``待审核`` 状态的成果通常可在 ``操作`` 列编辑；已进入
  审核流程的成果不可修改。

- **积分记录异常怎么办？**
  在 ``积分流水`` 中核对变动记录。如确认异常，提交工单联系管理员。
