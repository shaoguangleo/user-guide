查看平台通知
==================

流程目标
^^^^^^^^

帮助用户及时发现系统通知和重要消息。

进入方式
^^^^^^^^

普通用户侧栏没有 ``通知中心`` 菜单。可通过以下方式进入：

- 工作台 ``快捷操作`` 中的 ``通知中心`` 按钮（路径
  通知中心页面）。
- 工作台 ``平台通知`` 卡片右上角的 ``查看全部`` 链接。

页面内容
^^^^^^^^

通知中心页面顶部显示四个统计：``全部通知``、``未读通知``、``重要通
知``、``重要``。下方是筛选条件 ``类型`` ``分类`` ``状态``。

主体是通知列表表格，列包含 ``状态`` ``标题`` ``类型`` ``分类`` ``发布
时间``。每行右上角的圆形按钮可用于标记已读/未读。

.. figure:: /_static/notification-center.png
   :alt: 通知中心
   :width: 90%

   通知中心页面，显示通知列表与筛选条件。

查看通知详情
^^^^^^^^^^^^

1. 在通知列表中找到需要查看的通知行。
2. 点击通知标题行展开详情（如页面支持）或查看完整描述。
3. 点击右侧圆形按钮将通知标记为已读，状态从 ``未读`` 变为 ``已读``。

筛选通知
^^^^^^^^

1. 在 ``类型`` 下拉框中选择通知类型（如 ``系统通知``）。
2. 在 ``分类`` 下拉框中选择分类。
3. 在 ``状态`` 下拉框中选择 ``已读`` 或 ``未读``。
4. 列表自动刷新显示符合条件的通知。

常见问题
^^^^^^^^

- **没有收到通知怎么办？**
  检查通知中心 ``全部通知`` 列表确认是否已发布；如确认未收到，请提交
  工单联系管理员。
