提交问题工单
===================

流程目标
^^^^^^^^

帮助用户在遇到问题时提交完整、可处理的工单。

进入方式
^^^^^^^^

点击左侧菜单 ``工单管理``，进入工单页面。页面
默认显示 ``提交工单`` 表单。

页面内容
^^^^^^^^

``提交工单`` 表单包含字段：

- ``工单标题``：不超过 255 字符。
- ``工单分类``：默认 ``其他``，可根据问题类型选择。
- ``优先级``：默认 ``普通``。
- ``工单描述``：不超过 5000 字符，建议按模板填写（见下文）。
- ``联系人姓名``、``联系邮箱``、``联系电话``：可选联系方式。
- ``重 置`` 与 ``提交工单`` 两个按钮。

.. figure:: /_static/ticket-submit.png
   :alt: 提交工单表单
   :width: 90%

   提交工单表单，包含标题、分类、优先级、描述等字段。

提交工单流程
^^^^^^^^^^^^

1. 在 ``工单标题`` 输入框中简要描述问题（例如 ``应用启动失败``）。
2. 选择 ``工单分类`` 与 ``优先级``。
3. 在 ``工单描述`` 中按工单描述模板填写。
4. 如需回复，填写 ``联系人姓名``、``联系邮箱``、``联系电话``。
5. 点击 ``提交工单`` 按钮。
6. 看到成功提示后，进入 ``我的工单`` 查看刚提交的工单。

.. figure:: /_static/ticket-filled.png
   :alt: 工单填写示例
   :width: 90%

   工单填写示例。

工单描述模板
^^^^^^^^^^^^

建议在 ``工单描述`` 中按以下格式填写：

- ``问题页面``：访问的具体页面名称或路径。
- ``发生时间``：出现问题的时间点。
- ``操作步骤``：触发出问题的具体步骤。
- ``实际结果``：页面实际显示的内容或报错信息。
- ``期望结果``：期望的正常表现。
- ``相关应用或作业 ID``：如有关联的应用名或作业 ID，请填写。

查看我的工单
^^^^^^^^^^^^

1. 在工单管理页面顶部点击 ``我的工单`` 标签。
2. 在列表中找到刚提交的工单。
3. 点击工单行打开详情，查看状态和处理进度。

.. figure:: /_static/ticket-list.png
   :alt: 我的工单
   :width: 90%

   我的工单列表。

常见问题
^^^^^^^^

- **工单提交失败怎么办？**
  检查 ``工单标题`` 是否已填写、``工单描述`` 是否超出 5000 字符限制；
  修正后重新提交。

- **页面提示权限不足怎么办？**
  确认当前登录账号是普通用户角色；如账号异常请提交另一个工单联系管理
  员处理。
